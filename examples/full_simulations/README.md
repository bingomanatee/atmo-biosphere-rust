# 🌍 Full Simulations

Complete, production-ready examples that demonstrate full simulation workflows with multiple components working together.

## Examples in this folder:

### `adaptive_hotspot_demo.rs`
Complete hotspot simulation with adaptive behavior, showing how hotspots evolve over geological time.

**Features:**
- Adaptive hotspot lifecycle management
- Multi-component interaction
- Realistic geological timescales
- Performance monitoring

**Run with:** `cargo run --example adaptive_hotspot_demo`

### `detailed_component_logging.rs`
Full simulation with comprehensive logging to understand what each component is doing.

**Features:**
- Detailed component-by-component logging
- Transaction tracking
- Performance metrics
- Debug output for development

**Run with:** `cargo run --example detailed_component_logging`

### `embedded_event_tracking.rs`
Complete simulation with event tracking to monitor simulation state changes.

**Features:**
- Event emission and handling
- State change tracking
- Event-driven analysis
- Real-time monitoring

**Run with:** `cargo run --example embedded_event_tracking`

### `event_emission_demo.rs`
Full demonstration of event emission and handling throughout a complete simulation.

**Features:**
- Comprehensive event system usage
- Event filtering and processing
- Event-based simulation control
- Event logging and analysis

**Run with:** `cargo run --example event_emission_demo`

## 🎯 Purpose

These examples are perfect for:
- **Production patterns** - See how to structure real simulations
- **Component integration** - Understand how components work together
- **Performance benchmarking** - Measure realistic simulation performance
- **Complete workflows** - From initialization to results

## 🚀 Getting Started

1. Start with `adaptive_hotspot_demo.rs` for a complete geological simulation
2. Use `detailed_component_logging.rs` to understand what's happening internally
3. Try `embedded_event_tracking.rs` for event-driven simulation monitoring
4. Explore `event_emission_demo.rs` for advanced event system usage
