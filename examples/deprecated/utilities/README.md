# 🛠️ Utilities

Reusable tools and helper examples that can be used across different projects and simulations.

## Examples in this folder:

### `reusable_performance_reporting.rs`
Performance measurement and reporting utilities for benchmarking simulations.

**Features:**
- Timing measurement utilities
- Memory usage tracking
- Performance report generation
- Benchmark comparison tools
- Statistical analysis helpers

**Run with:** `cargo run --example reusable_performance_reporting`

**Use in your code:**
```rust
// Copy the performance reporting functions into your simulation
// for detailed performance analysis
```

## 🎯 Purpose

These utilities are perfect for:
- **Performance analysis** - Measure and optimize simulation performance
- **Debugging tools** - Utilities to help debug simulation issues
- **Development helpers** - Tools to speed up development workflow
- **Reusable components** - Code you can copy into your own projects
