# 🧪 Proof of Concept Tests

Simple, focused examples that demonstrate specific concepts or test individual components.

## Examples in this folder:

### `simple_transaction_test.rs`
Basic transaction system demonstration showing how to create and apply transactions.

**Run with:** `cargo run --example simple_transaction_test`

### `test_event_system_simple.rs`
Simple event system testing with basic event emission and handling.

**Run with:** `cargo run --example test_event_system_simple`

### `standalone_event_system.rs`
Isolated event system proof of concept that doesn't depend on the full simulation.

**Run with:** `cargo run --example standalone_event_system`

### `geological_poc.rs`
Geological simulation proof of concept with basic layer and cell management.

**Run with:** `cargo run --example geological_poc`

## 🎯 Purpose

These examples are perfect for:
- **Learning** how individual components work
- **Testing** specific features in isolation
- **Quick prototyping** and experimentation
- **Understanding** core concepts before moving to full simulations

## 📚 Next Steps

Once you understand these concepts, move to `../full_simulations/` for complete use cases.
